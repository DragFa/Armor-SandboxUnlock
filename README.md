# Armor Sandbox + Unlock

- Open-source игрульки вытащеной с апк
- Версия: 2.6.0
- Вытащил и слил krksh
- Добавил папку с полностью снятыми ограничениями, то есть помимо стандартной игры, есть версия без ограничений.
Короче, это песочница с физикой. Собираешь снаряд, выбираешь мишень или машину и смотришь, как оно всё гнётся, ломается, горит и разлетается.

## Что тут лежит

- Ориг веб-сборка Armor Sandbox 2.6.0 из APK
- HTML, JavaScript, графика, звук и готовые эксперименты
- Flask, чтобы запустить игру в обычном браузере
- Конструктор снарядов и мишеней
- Танки, машины, постройки и разные материалы
- Симуляция удара, разрушений, нагрева и всякого другого

Исходного TypeScript тут нет - это собранный JS из APK. Android-оболочка для запуска не нужна. Проверку запуска в WebView адаптировал под браузер, остальная логика игры сохранена.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python app.py
```

Открывай http://127.0.0.1:5001/

На Windows можно проще:

```powershell
.\start.ps1
```

Другой порт:

```bash
python app.py --port 8080
```

## По папкам

- `web/` - сама игрулька и её файлы
- `app.py` - сервер Flask
- `requirements.txt` - зависимости Python
- `start.ps1` - запуск на Windows

Нужен нормальный браузер с WebGL2. Для телефона удобнее горизонтальное положение. Своё сохраняется в браузере, так что не сноси данные сайта, если там есть нужные постройки.
